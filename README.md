# 🏪 ร้านค้า POS

ระบบขายหน้าร้านสำหรับร้านขายของชำขนาดเล็ก

## วิธีรัน
1. เปิดใน VS Code
2. ติดตั้ง extension "Live Server"
3. คลิกขวาที่ `index.html` → **Open with Live Server**
4. เปิด browser ที่ http://localhost:8080

## ฟีเจอร์
- ขายสินค้า + ตะกร้า
- เงินสด + ทอนอัตโนมัติ
- QR PromptPay
- จัดการสินค้า + หมวดหมู่
- ประวัติการขาย + รายงาน 7/30 วัน
- Backup / Restore
- PIN ล็อก

## โครงสร้าง
- `index.html` — หน้าเว็บหลัก
- `css/style.css` — สไตล์ทั้งหมด
- `js/` — โค้ด JavaScript แยกตามหน้าที่
